# Delicious Restaurant Website

A modern and responsive restaurant website built from scratch using HTML and CSS.

## 📌 About the Project

This project is a restaurant website created as part of my Web Development practice.

The website focuses on creating a clean, modern, and responsive user interface with multiple sections for a restaurant.

## 🚀 Features

- Responsive navigation bar
- Hero section
- About section
- Restaurant menu
- Services section
- Contact section
- Contact form
- Footer with social links
- Responsive design for mobile devices
- Smooth and modern UI
